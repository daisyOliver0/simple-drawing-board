# Simple Drawing Board

An interactive browser-based drawing canvas.

## Features

- Custom brush colors
- Adjustable brush size
- PNG export

## How to Use

Choose a brush and draw on the canvas.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
## Manual Testing Checklist

- [ ] Draw a short line using a mouse or touch.
- [ ] Change brush size and color before drawing again.
- [ ] Clear the canvas and export a test PNG image.
